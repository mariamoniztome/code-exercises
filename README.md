# Code Exercises

Repositório pessoal de exercícios e projetos de aprendizagem, organizado por área/tecnologia. Cada pasta principal agrupa vários mini-projetos independentes — consulta o README de cada um para detalhes.

## Projetos

- **[Backend](./Backend/README.md)** — exercícios de Node.js/Express: rotas, middleware, autenticação, SQLite e MongoDB.
- **[Design System](./Design%20System/README.md)** — sistema de design em React + Tailwind + shadcn/ui, com tokens, componentes e padrões de UI.
- **[ML5.js](./ML5.js/READMe.md)** — sistema solar interativo em 3D, feito com p5.js e ml5.js.
- **[P5.js](./P5.js/README.md)** — exercícios de sistemas de partículas com p5.js.
- **[Three.js](./Three.js/README.md)** — exercícios do curso Three.js Journey: modelos 3D, física, environment maps, partículas, raycasting e animações com scroll.

## Estrutura

Cada subpasta é um projeto autónomo (com o seu próprio `package.json` quando aplicável) e não depende das restantes.
